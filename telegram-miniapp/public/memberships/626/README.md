# Arte de membresías · 626 Café

Deja aquí los archivos y se referencian desde `membership_plans.coverImageUrl`
con ruta relativa, por ejemplo:

```
/memberships/626/nido-familiar-626.webp
```

## Nombres

| Uso | Archivo | Formato |
|---|---|---|
| Tarjeta en la app | `nido-familiar-626.webp` | WebP animado, loop, 1600×900, ≤ 500 KB |
| Respaldo estático | `nido-familiar-626.png` | PNG 2048×2048 (imagen del NFT) |
| Movimiento para marketplace | `nido-familiar-626.mp4` | MP4 H.264, 1920×1080, ≤ 5 MB, loop de 3–6 s |

No usar GIF: 256 colores y 3–10× más peso que WebP para el mismo movimiento.

## Reglas de arte

- Zona segura: deja 12% de margen en los bordes (se recorta en la tarjeta).
- Texto legible sobre el fondo; evita texto pequeño (< 28 px en 1200×1200).
- Paleta 626: terracota `#C2703D`, crema `#F6EBDD`, café `#3B2A22`.
- La tarjeta muestra la imagen arriba y los beneficios debajo; el QR va al final.
